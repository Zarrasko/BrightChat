## BrightChat v2.33 — unstar a chat the way you starred it

**Long-press is now star/unstar on every tab, and pinning moved to the swipe.**

Starring a chat was a one-way trip in practice. The long-press that starred it also lived on
the Favorites tab, but there it *pinned* instead of unstarring — so the only way to undo a
star was a swipe-left reveal nobody knew to look for, and a starred chat looked like it could
never be unstarred. The same long-press that stars a chat now unstars it: on Favorites the
chat drops back to Messages, and any pin goes with it.

Pinning is still there, one swipe away. On Favorites, sliding a row left reveals **Pin** or
**Unpin** (that reveal was the hidden **Unstar** before). Delete keeps the same swipe, one tab
over on Messages, and starring from Messages/Unknown is unchanged.
